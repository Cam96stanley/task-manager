# CLI Task Manager

## About the project

In this project, I created a to-do list command line program. I implemented 3 different functions to add, view, and delete tasks and created a main function to handle the 3 functions along with the user display. The tasks are stored in a list which is mutated to append or pop tasks or in 'view_tasks', it loops over the list to create a enumerated list of all the tasks. I implemented try and except blocks for the delete function to catch errors.

## Usage

1. Run the program with <code>python3 task_manager.py</code>
2. In the CLI, enter the number corresponding to the function you want to run
3. Follow prompts to create, view, delete, or exit the program
